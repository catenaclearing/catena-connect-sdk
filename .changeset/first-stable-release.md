First stable release. Install without the `@beta` tag: `npm install @catenaclearing/connect-sdk`, or `@catenaclearing/connect-sdk-react` for React. The API is the same as `1.0.0-beta.12` (core) and `1.0.0-beta.7` (React), and the versioning and support policy applies from this release. The READMEs drop the beta install notes. No runtime change.
